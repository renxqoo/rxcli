# 输出格式规范

> SKILL.md「输出判断原则」讲了为什么判断,本文件教怎么展示。所有 AI 输出遵循本规范。
>
> 🔒 输出时禁止暴露 `CORDYS_ACCESS_KEY`/`CORDYS_SECRET_KEY`。API 错误含密钥信息须脱敏。

---

## 第一性原则

判断的原则与四层结构(关键结论 → 核心数据 → 异常提醒 → 建议动作)见 SKILL.md「输出判断原则」。本文件聚焦**怎么展示**。

---

## Emoji 状态规范

全局统一使用,避免语义混乱:

| emoji | 含义 | 用于 |
|-------|------|------|
| 🟢 | 正常、已完成、活跃 | 状态正常、活跃客户 |
| ✅ | 已完成、已处理 | 已转化、已回款、已审批 |
| ⚠️ | 需要注意、即将过期 | 超 3 天未跟进、即将到期 |
| 🚨 | 紧急、逾期、异常 | 从未跟进、严重逾期、断链 |
| 📋 | 计划、提醒 | 今日待办、待审批 |
| 📊 | 统计、概览 | 月报、漏斗、排名 |
| 💰 | 金额、回款 | 回款统计 |
| 🔗 | 链路、关联 | L2C 追踪 |

---

## 表格规则

- 用标准 Markdown 表格(不手画 ASCII 框线)
- **列数 ≤ 5**,多字段分批展示
- 关键值(金额、日期、状态)放前列
- 金额带单位(¥/万)
- 时间用 `YYYY-MM-DD`(时间戳需转换,勿直接贴毫秒数)

## 通用列表查询输出

### 列表(以销售视角为例)
```
📋 您本月有 13 条线索,其中 3 条需要关注:

| 客户名称 | 创建时间 | 阶段 | 状态 |
| --- | --- | --- | --- |
| XXX 科技 | MM-DD | NEW | 🟢 新 |
| YYY 集团 | MM-DD | NEW | 🚨 从未跟进 |

🚨 YYY 集团从未跟进,建议今日优先联系
```

### 单条详情
```
🏢 客户详情:华星科技

| 字段 | 值 |
|------|-----|
| 行业 | 科技 |
| 省份 | 广东 |
| 负责人 | 李四 |
| 最近跟进 | YYYY-MM-DD |

(其他字段按需展示)
```

### 空结果
```
📌 当前筛选下无 {模块} 数据
💡 建议:放宽筛选条件(如时间范围、关键词),或确认模块名是否正确
```

> 区分"确实没有"和"筛选太严":用户带了筛选 → 提示放宽;未带筛选 → 提示系统暂无。

---

## 大结果集处理

| 返回条数 | 展示方式 |
|---------|---------|
| 1-10 条 | 完整表格 |
| 11-30 条 | 前 10 条 + "还有 N 条,是否查看更多?" |
| 30 条以上 | 统计摘要 + 前 10 条 + "建议增加筛选条件" |

## 写入操作输出

### 创建成功
```
✅ 已创建客户「华星科技」

| 字段 | 值 |
|------|-----|
| ID | {id} |
| 名称 | 华星科技 |
| ... | ... |

🔗 查看:rxcordys accounts get {id}
```

### 更新成功(变更对比)
```
✅ 已更新客户「华星科技」

| 字段 | 旧值 | 新值 |
|------|------|------|
| 行业 | 科技 | 金融 |
| 省省 | 北京 | 上海 |
```

### 批量操作结果
```
✅ 批量更新完成

| 结果 | 数量 |
|------|------|
| 成功 | {N} 条 |
| 失败 | {M} 条 |

(失败明细,如有)
```

### 线索转化成功
```
🔄 线索「{线索名}」已转化

✅ 客户「{客户名}」已创建
✅ 商机「{商机名}」¥{金额} 已创建(如有)

🔗 客户详情:rxcordys accounts get {id}
```

> 写入前默认需确认(SKILL.md「写入操作」节)。所有写入命令用 `--dry-run` 校验/预览、`--yes` 执行,不带 `--yes` 返回 exit 10。

## 全局模糊搜索输出

跨模块搜索时(如 `util glocount` + 各模块 `search`),按模块分段展示:

```
🔍 全局搜索:"华星科技"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 线索(8 条)
| 名称 | 公司 | 负责人 | 创建时间 |
| --- | --- | --- | --- |

📌 客户(2 条)
| 名称 | 行业 | 负责人 |
| --- | --- | --- |

📌 商机(2 条)
| 名称 | 金额 | 阶段 |
| --- | --- | --- |

📌 公海(0 条) — 无匹配

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 汇总:共找到 {总数} 条匹配
💡 客户"华星科技"名下有关联商机,建议查看客户 360
```

### 搜索输出规则

| 规则 | 说明 |
|------|------|
| 有数据才展开 | 命中 0 的模块仅单行显示"无匹配",不展开表格 |
| 按优先级排序 | 线索、客户在前(高优),商机居中,联系人在后 |
| 表格 ≤5 列 | 按模块特性选关键字段 |
| 汇总行 | 含总命中数 |
| 行动建议 | 多模块命中时指出关联性(见下) |

### 行动建议规则

| 场景 | 建议 |
|------|------|
| 线索 + 客户同时命中 | `💡 客户"{名称}"名下有关联记录,建议查看客户 360` |
| 线索+客户+商机同时命中 | `💡 检测到完整链路:线索→客户→商机,建议查看客户 360` |
| 仅 1 个模块命中 | `💡 仅在 {模块} 匹配到 {N} 条,是否扩大搜索范围?` |
| 无任何匹配 | `💡 未找到相关记录,请检查关键词` |
| 总结果 > 30 条 | `💡 结果较多,建议增加筛选条件或指定模块` |
