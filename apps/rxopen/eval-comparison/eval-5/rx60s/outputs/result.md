## 为什么我"恰好"加了 --symbols(诚实复盘)

这是本次任务的核心考点。我之所以知道要加 `--symbols`,完全是因为读了 rx60s 的 SKILL.md。

**SKILL.md 里有一段专门的"易踩坑提示(参数默认值/非显然值)"**,原文明确写着:

> **`tool password` 的 `--symbols` 默认关**:用户要"含特殊符号的密码"必须显式加 `--symbols`,否则只生成字母+数字。其它(`--numbers`/`--lowercase`/`--uppercase`)默认开。

这句话精准命中了用户"要包含特殊符号"这个诉求。如果没有这段提示,只看 `--help`:

```
[--length <number>] [--numbers] [--symbols] [--lowercase] [--uppercase] ...
```

`--symbols` 和 `--numbers`/`--lowercase`/`--uppercase` 长得一模一样,**没有任何线索表明"只有 symbols 是默认关、其它三个默认开"**。我极大概率会直接 `rx60s tool password --length 20`,拿到一串纯字母数字密码就交差。

为了验证这个判断,我对照跑了一次**不加 `--symbols`** 的:

| | 不加 --symbols(踩坑) | 加 --symbols(本次实际) |
|---|---|---|
| 密码 | `9J2bDSZFnqksygxz59TT` | `A!8#%T_X3tw@@n^F2!6A` |
| `include_symbols` | `false` | `true` |
| 符号字符集 | `""`(空) | `!@#$%^&*_+-=|:?` |
| 是否含特殊符号 | ❌ 不含 | ✅ 含 |

**结论:rx60s 的"易踩坑提示"帮我避开了"默认值陷阱",生成的密码真正满足用户"包含特殊符号"的核心诉求。**
