# rxopen-life —— 生活服务

天气、油价、金价、汇率、老黄历、历史上的今天、奥运奖牌、健康评估(BMI)等生活数据。数据来自 [vikiboss/60s](https://github.com/vikiboss/60s) 开源项目(MIT License © Viki),数据版权归原项目及原始数据源所有。

## 安装与运行

```bash
npx @renxqoo/rxopen-cli install  # 一键安装
rxopen life weather 上海          # 上海实时天气
```

## 输出格式

默认 JSON 统一输出(agent / 管道用):

```json
{ "ok": true, "source": "rxopen", "data": { ... }, "meta": { ... } }
```

人类可读(终端用)加 `--no-json`:

```bash
rxopen life weather 上海 --no-json   # 天气卡片
```

## 典型用法

```bash
rxopen life weather 北京          # 实时天气(位置参数:城市名,不是 --query)
rxopen life forecast 上海 --days 5 # 天气预报
rxopen life fuel-price --region 广东 # 今日油价
rxopen life gold-price            # 贵金属金价
rxopen life exchange-rate --currency USD  # 美元汇率
rxopen life lunar                 # 今日老黄历/万年历
rxopen life today-in-history      # 历史上的今天
rxopen life olympics              # 奥运奖牌榜
rxopen health assess --height 175 --weight 70 --gender male --age 30  # BMI 评估
```

## 易踩坑提示(参数默认值/非显然值)

- **`life weather` 城市是位置参数**:`rxopen life weather 上海`(不是 `--query 上海`)。
- **`health assess` 四个参数全必填**:`--height`(cm)、`--weight`(kg)、`--gender`(male/female)、`--age`(岁)。缺任何一个都报 `invalid_argument`。
- **`life fuel-price` 的 `--region` 是后缀匹配**:`--region 广东` 匹配"广东省";省略默认"北京"。

## 前置条件

- **无需登录**:全部公开数据。直接调用即可。
- 公共数据源可能限流(429),稍后重试或自部署(设 `RXOPEN_BASE_URL`)。

## 错误处理

| 错误 | 含义 | 处理 |
|------|------|------|
| `not_found` / exit 1 | 城市未找到、记录不存在 | 检查参数;用更通用的城市名 |
| `invalid_argument` / exit 2 | 参数不合法(如缺必填、值超范围) | 看 `--help` 或 reference 查约束 |
| exit 4 网络错误 | 连不上数据源 | 稍后重试 |
| `rate_limited` / exit 1 (429) | 公共实例限流 | 稍后重试,或自部署 |
| `server_error` / exit 1 (5xx) | 上游异常 | 稍后重试 |
