# rxopen-fun —— 趣味文案与摸鱼日历

一言、段子、冷笑话、发病文学、疯狂星期四、答案之书、今日运势、打工人日历(摸鱼办)。数据来自 [vikiboss/60s](https://github.com/vikiboss/60s) 开源项目(MIT License © Viki),数据版权归原项目及原始数据源所有。

## 安装与运行

```bash
npx @renxqoo/rxopen-cli install  # 一键安装
rxopen hitokoto                   # 来一句一言
rxopen moyu                       # 摸鱼日历(离放假还有几天)
```

## 输出格式

默认 JSON 统一输出(agent / 管道用):

```json
{ "ok": true, "source": "rxopen", "data": { "index": 2403, "hitokoto": "..." } }
```

人类可读(终端用)加 `--no-json`。

## 输出示例

```bash
$ rxopen hitokoto --json
{"ok":true,"source":"rxopen","data":{"index":2403,"hitokoto":"一过岁,不就是老女人了嘛!"}}
```

## 典型用法

```bash
rxopen hitokoto                   # 一言(顶层快捷 = fun hitokoto)
rxopen fun hitokoto               # 同上
rxopen fun hitokoto --id 100      # 指定 id
rxopen fun duanzi                 # 段子
rxopen fun dad-joke               # 冷笑话(英文)
rxopen fun fabing --name 张三      # 发病文学(替换 [name] 为张三)
rxopen fun kfc                    # 疯狂星期四文案
rxopen fun answer                 # 答案之书
rxopen fun luck                   # 今日运势
rxopen moyu                       # 摸鱼日历(顶层快捷)
rxopen fun moyu --date 2026-12-31 # 指定日期的打工人日历
```

## 前置条件

- **无需登录**:全部公开数据。直接调用即可。
- 公共数据源可能限流(429),稍后重试或自部署(设 `RXOPEN_BASE_URL`)。

## 错误处理

| 错误 | 含义 | 处理 |
|------|------|------|
| `not_found` / exit 1 | 指定的 `--id` 越界 | 省略 id 取随机,或用更小的 id |
| exit 4 网络错误 | 连不上数据源 | 稍后重试 |
| `rate_limited` / exit 1 (429) | 公共实例限流 | 稍后重试,或自部署 |
| `server_error` / exit 1 (5xx) | 上游异常 | 稍后重试 |
