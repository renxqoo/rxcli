# rxopen-fun

## 执行规则

1. 先检查 `rxopen` 是否在 PATH（如 `command -v rxopen`）；不可用时读取 `references/install.md`，向用户说明安装步骤。
2. 调用业务命令时加 `--json`，从 `data` 读取结果。
3. 用户指定名称时把名称传给 `fun fabing --name`；未指定时不要擅自代入真实人物。
4. `fun dad-joke` 返回英文。用户要求中文时可翻译，但要标明是译文。
5. `--id` 无效时省略它获取随机内容，不要连续猜测 ID。
