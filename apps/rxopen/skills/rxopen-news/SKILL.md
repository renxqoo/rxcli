# rxopen-news —— 新闻资讯

每日新闻速览、AI/IT 行业资讯、RSS 订阅、必应每日壁纸、Hacker News。数据来自 [vikiboss/60s](https://github.com/vikiboss/60s) 开源项目(MIT License © Viki),数据版权归原项目及原始数据源所有,本项目仅做 CLI 化。

## 安装与运行

```bash
npx @renxqoo/rxopen-cli install  # 一键安装(同步 skill 到已装的 AI 工具发现目录)
# 或直接用(已全局安装)
rxopen daily                      # 今天有什么新闻?
```

## 输出格式

默认 JSON 统一输出(agent / 管道用):

```json
{ "ok": true, "source": "rxopen", "data": { ... }, "meta": { ... } }
```

人类可读(终端用)加 `--no-json`(框架渲染卡片/表格;**管道下游时强制 JSON**,保护下游解析):

```bash
rxopen daily --no-json            # 卡片式新闻
```

## 典型用法

```bash
rxopen daily                      # 每日新闻速览(新闻摘要 + 微语,项目核心)
rxopen news today                 # 同上(namespaced 别名)
rxopen news ai                    # 今日 AI 行业资讯
rxopen news it --limit 10         # IT 之家最新 10 条
rxopen news it-rank --type week   # IT 之家周榜
rxopen news rss                   # 近 7 天 RSS 订阅
rxopen tech hackernews --limit 5  # Hacker News top 5
rxopen bing                       # 必应每日壁纸(标题 + 1080P/4K)
```

## 前置条件

- **无需登录**:全部公开数据,无鉴权。直接调用即可。
- 公共数据源可能限流(429),稍后重试或自部署(设 `RXOPEN_BASE_URL`)。

## 错误处理

| 错误 | 含义 | 处理 |
|------|------|------|
| `not_found` / exit 1 | 记录不存在(如越界日期) | 检查参数 |
| `invalid_argument` / exit 2 | 参数不合法 | 看 `--help` 或 reference 查约束 |
| exit 4 网络错误 | 连不上数据源 | 稍后重试 |
| `rate_limited` / exit 1 (429) | 公共实例限流 | 稍后重试,或自部署 |
| `server_error` / exit 1 (5xx) | 上游异常 | 稍后重试 |
