# rxopen-tool —— 开发者工具

翻译、Hash/编码转换、二维码、密码生成与检测、域名/IP 查询、颜色/配色、化学物质、百科、JS 面试题等开发工具。数据来自 [vikiboss/60s](https://github.com/vikiboss/60s) 开源项目(MIT License © Viki),数据版权归原项目及原始数据源所有。

## 安装与运行

```bash
npx @renxqoo/rxopen-cli install  # 一键安装
rxopen tool fanyi "hello" --to zh-CHS   # 翻译
```

## 输出格式

默认 JSON 统一输出(agent / 管道用):

```json
{ "ok": true, "source": "rxopen", "data": { ... }, "meta": { ... } }
```

人类可读(终端用)加 `--no-json`。

## 典型用法

```bash
rxopen tool fanyi hello --to zh-CHS           # 有道翻译(英→中)
rxopen tool fanyi-langs                       # 翻译支持的语言列表
rxopen tool hash "content"                    # MD5/SHA/Base64/URL 编码
rxopen tool qrcode "https://example.com" --size 300  # 二维码(返回 base64/data_uri)
rxopen tool whois baidu.com                   # 域名 WHOIS
rxopen tool ip                                # 我的 IP 归属
rxopen tool ip --ip 8.8.8.8                   # 指定 IP 归属
rxopen tool password --length 20 --symbols    # 20 位含符号密码
rxopen tool password-check "mypassword123"    # 密码强度检测
rxopen tool color --color "#FF5733"           # 颜色信息(HEX/RGB/HSL...)
rxopen tool color-palette --color "#FF5733"   # 配色方案
rxopen tool chemical                          # 随机化学物质(分子式/结构式)
rxopen kb baike 人工智能                       # 百度百科词条摘要
rxopen kb js-question                         # 随机 JS 面试题
rxopen beta qq 12345678                       # QQ 用户信息(实验性)
rxopen beta kuan                              # 酷安热门话题(实验性)
```

## 易踩坑提示(参数默认值/非显然值)

这些点光看 `--help` 容易踩坑,优先查 reference:

- **`tool password` 的 `--symbols` 默认关**:用户要"含特殊符号的密码"必须显式加 `--symbols`,否则只生成字母+数字。其它(`--numbers`/`--lowercase`/`--uppercase`)默认开。
- **`tool fanyi` 目标语言代码**:`中文=zh-CHS`、英语=en、日语=ja、韩语=ko、法语=fr、德语=de、俄语=ru。完整列表跑 `tool fanyi-langs`(不能瞎猜代码)。
- **`tool color` 用 `--color`**:`rxopen tool color --color "#FF5733"`(注意是 flag 不是位置参数)。
- **`tool qrcode` 不直接产图片文件**:返回 `base64` + `data_uri` 字段,用 `data_uri` 直接做 `<img src>`。
- **`beta` 命令是实验性接口**:上游标记不稳定,可能随时失效。

## 前置条件

- **无需登录**:全部公开数据。直接调用即可。
- 公共数据源可能限流(429),稍后重试或自部署(设 `RXOPEN_BASE_URL`)。

## 错误处理

| 错误 | 含义 | 处理 |
|------|------|------|
| `not_found` / exit 1 | 词条未找到、域名未注册 | 检查参数 |
| `invalid_argument` / exit 2 | 参数不合法(如缺必填、翻译语言代码无效) | 看 `--help` 或 reference 查约束 |
| exit 4 网络错误 | 连不上数据源 | 稍后重试 |
| `rate_limited` / exit 1 (429) | 公共实例限流 | 稍后重试,或自部署 |
| `server_error` / exit 1 (5xx) | 上游异常 | 稍后重试 |
