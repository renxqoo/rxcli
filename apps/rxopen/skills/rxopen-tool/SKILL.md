# rxopen-tool

## 安全边界

- `hash`、`qrcode`、`password-check`、翻译等命令会把输入发送到远程上游。不得传入真实密码、令牌、私钥、身份证号或其他敏感数据。
- `password` 返回的密码由远程服务生成，不用于重要账户；真实凭证使用可信的本地密码管理器生成。

## 执行规则

1. 先检查 `rxopen` 是否在 PATH（如 `command -v rxopen`）；不可用时读取 `references/install.md`，向用户说明安装步骤。
2. 调用业务命令时加 `--json`。
3. 翻译语言代码不确定时先调用 `tool fanyi-langs`，不要猜测。
4. 用户要求含符号密码时显式加 `--symbols`。仅用虚构密码演示 `password-check`。
5. `qrcode` 返回 `base64` 和 `data_uri`。用户要求图片文件时，将结果解码到用户指定路径并返回文件。
6. `chemical` 仅支持随机结果或 ChemSpider ID，不支持按名称搜索。
7. `beta` 命令不稳定；失败时说明实验性接口不可用，不连续重试。
