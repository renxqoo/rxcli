# rxopen-media —— 音乐与影视

网易云音乐榜单/歌词、唱鸭翻唱、猫眼全球/实时票房、豆瓣口碑榜、Epic 免费游戏。数据来自 [vikiboss/60s](https://github.com/vikiboss/60s) 开源项目(MIT License © Viki),数据版权归原项目及原始数据源所有。

## 安装与运行

```bash
npx @renxqoo/rxopen-cli install  # 一键安装
rxopen music rank                 # 网易云榜单列表
```

## 输出格式

默认 JSON 统一输出(agent / 管道用):

```json
{ "ok": true, "source": "rxopen", "data": { ... }, "meta": { ... } }
```

人类可读(终端用)加 `--no-json`。

## 典型用法

```bash
rxopen music rank                       # 网易云榜单列表(拿榜单 ID)
rxopen music rank-detail 3778678        # 热歌榜曲目(3778678 = 热歌榜 ID)
rxopen music lyric "晴天"                # 歌词搜索(QQ 音乐源)
rxopen music changya                     # 唱鸭随机翻唱(含音频 URL)
rxopen movie maoyan-all                  # 猫眼全球票房总榜
rxopen movie maoyan-realtime             # 今日实时票房
rxopen movie douban                      # 豆瓣一周口碑榜(默认电影)
rxopen movie douban --cat tv_chinese     # 豆瓣华语剧口碑榜
rxopen movie epic                        # Epic 免费游戏(当前 + 即将)
```

## 易踩坑提示

- **`music rank-detail` 要先拿 ID**:榜单 ID(如 `3778678` 热歌榜、`19723756` 飙升榜)从 `music rank` 列表里取,不能瞎编。
- **`movie douban` 的 `--cat` 枚举**:`movie`(电影,默认)、`tv_chinese`(华语剧)、`tv_global`(全球剧)、`show_chinese`(华语综艺)、`show_global`(全球综艺)。
- **`movie maoyan-realtime` 的 `--type`**:`movie`(电影,默认)、`tv`、`web`(网播)。

## 前置条件

- **无需登录**:全部公开数据。直接调用即可。
- 公共数据源可能限流(429),稍后重试或自部署(设 `RXOPEN_BASE_URL`)。

## 错误处理

| 错误 | 含义 | 处理 |
|------|------|------|
| `not_found` / exit 1 | 榜单 ID 不存在 | 用 `music rank` 查有效 ID |
| `invalid_argument` / exit 2 | 参数不合法(如 cat/type 枚举值错) | 看 reference 查枚举 |
| exit 4 网络错误 | 连不上数据源 | 稍后重试 |
| `rate_limited` / exit 1 (429) | 公共实例限流 | 稍后重试,或自部署 |
| `server_error` / exit 1 (5xx) | 上游异常 | 稍后重试 |
