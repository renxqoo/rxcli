# rxopen-media

## 执行规则

1. 先检查 `rxopen` 是否在 PATH（如 `command -v rxopen`）；不可用时读取 `references/install.md`，向用户说明安装步骤。
2. 调用业务命令时加 `--json`。
3. 用户要某个榜单的曲目时，先用 `music rank` 查当次返回的榜单 ID，再调用 `music rank-detail`；不要猜或硬编码 ID。
4. `music lyric` 使用 QQ 音乐数据源，不要表述为网易云歌词。按适用的内容引用限制回答，不默认复述整首歌词。
5. `movie maoyan-all` 是全球电影票房总榜；当前电影、电视或网播数据使用 `movie maoyan-realtime` 并选择正确 `--type`。
6. 榜单 ID 或枚举无效时读取 reference 修正参数，不连续试错。
