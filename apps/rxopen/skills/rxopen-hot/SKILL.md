# rxopen-hot

## 执行规则

1. 先检查 `rxopen` 是否在 PATH（如 `command -v rxopen`）；不可用时读取 `references/install.md`，向用户说明安装步骤。
2. 调用对应平台命令并加 `--json`。用户未指定平台时先确认；明确要求多平台时改用 `rxopen-trending`。
3. 各命令返回数组，只有 `title` 可视为稳定共性字段；解析热度、链接或摘要前读取 `references/hot.md`。
4. 把结果表述为调用时刻的榜单快照。榜单上榜不代表内容真实，不据此作事实确认。
5. 上游失败时返回原始错误，不用其他平台结果冒充目标平台。
