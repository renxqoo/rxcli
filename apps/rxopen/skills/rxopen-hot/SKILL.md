# rxopen-hot —— 热搜榜单

各平台实时热搜榜单(微博/知乎/头条/抖音/B站/小红书/百度/懂车帝/夸克等 11 个平台),**所有子命令无参数**,返回数组。数据来自 [vikiboss/60s](https://github.com/vikiboss/60s) 开源项目(MIT License © Viki),数据版权归原项目及原始数据源所有。

## 安装与运行

```bash
npx @renxqoo/rxopen-cli install  # 一键安装
rxopen hot weibo                  # 微博热搜
```

## 输出格式

默认 JSON 统一输出(agent / 管道用):

```json
{ "ok": true, "source": "rxopen", "data": [{ "title": "...", "hot_value": 123, "link": "..." }], "meta": { "count": 50, "pagination": { "complete": true } } }
```

人类可读(终端用)加 `--no-json`:

```bash
rxopen hot weibo --no-json        # 热搜表格
```

## 典型用法

```bash
rxopen weibo                      # 顶层快捷 = hot weibo
rxopen hot weibo                  # 微博实时热搜
rxopen hot zhihu                  # 知乎实时热搜
rxopen hot douyin                 # 抖音实时热搜
rxopen hot bili                   # B 站实时热搜

rxopen hot dongchedi              # 懂车帝热搜

```

## 前置条件

- **无需登录**:全部公开数据。直接调用即可。
- 公共数据源可能限流(429),稍后重试或自部署(设 `RXOPEN_BASE_URL`)。

## 错误处理

| 错误 | 含义 | 处理 |
|------|------|------|
| exit 4 网络错误 | 连不上数据源 | 稍后重试 |
| `rate_limited` / exit 1 (429) | 公共实例限流 | 稍后重试,或自部署 |
| `server_error` / exit 1 (5xx) | 上游异常 | 稍后重试 |
