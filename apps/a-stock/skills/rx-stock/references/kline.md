## K 线参数详解

`rxstock kline get <code>` 支持的参数:

### `--period` 周期

| 值                          | 含义   | 数据源               |
| --------------------------- | ------ | -------------------- |
| `day`                       | 日 K   | 腾讯 + 东财          |
| `week`                      | 周 K   | 腾讯 + 东财          |
| `month`                     | 月 K   | 腾讯 + 东财          |
| `year`                      | 年 K   | 腾讯(指数日级也走此) |
| `m1` `m5` `m15` `m30` `m60` | 分钟级 | 仅东财(腾讯不支持)   |

### `--adjust` 复权

| 值     | 含义                 |
| ------ | -------------------- |
| `none` | 不复权(默认)         |
| `qfq`  | 前复权(推荐用于回测) |
| `hfq`  | 后复权               |

### `--limit` 返回根数

腾讯单次最大约 800,东财最大约 1000。建议不超过 500 减少响应时间。

### `--start` / `--end` 日期区间

格式 `YYYY-MM-DD` 或 `YYYYMMDD`。指定后腾讯会按区间返回,东财会按根数返回。

## 字段说明

每根 K 线返回:

| 字段            | 说明                               |
| --------------- | ---------------------------------- |
| `date`          | 日期(YYYY-MM-DD) 或时间(分钟级)    |
| `open`          | 开盘价                             |
| `close`         | 收盘价                             |
| `high`          | 最高价                             |
| `low`           | 最低价                             |
| `volume`        | 成交量(手)                         |
| `amount`        | 成交额(元;东财才有,腾讯部分周期无) |
| `changePercent` | 当根涨跌幅(%;东财)                 |
| `change`        | 涨跌额(元;东财)                    |
| `turnoverRate`  | 换手率(%;东财)                     |

## 分时 / Tick 区别

- **分时 `kline minute`**:每分钟的累计价格和成交量走势,1 根 = 1 分钟
- **Tick `kline tick`**:每笔成交的明细(几秒一笔),数据量大,默认 100 笔

分时适合画日内走势图;Tick 适合精确还原成交过程。
